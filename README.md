| Skill | What it does | Get it |
|---|---|---|
| [Daily Tracker](daily-tracker/) | A daily board Claude runs for you: lanes for each business, Claude ticks tasks off as it finishes them, Recap at night. | [Page](daily-tracker/) · [zip for claude.ai](dist/daily-tracker.zip) |

More coming, one per video.

## Install any skill

**Claude Code:** clone once, then copy the skill folder you want.

```bash
git clone https://github.com/Inscaled-Academy/skills.git
cp -r skills/<skill-name> ~/.claude/skills/
```

Already cloned? `git pull` gets the new ones.

**claude.ai:** download the skill's zip from the table above, then Settings, Capabilities, Skills, upload.

Each skill's page says what to say to Claude to start it.
